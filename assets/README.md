# Mancalero media folders

Put final public assets in the matching folder. Keep filenames lowercase and use hyphens.

- `screenshots/`: PNG or JPG gameplay screenshots
- `gifs/`: short looping gameplay GIFs or MP4 previews
- `logos/`: horizontal, stacked, monochrome, and transparent logo variants
- `trailers/`: trailer, teaser, and clean B-roll files
- `press-kit/`: ZIP, PDF fact sheet, and ready-to-share press materials
- `downloads/`: creator B-roll ZIP and other large downloads
- `branding/`: capsule art, key art, palette, fonts, and usage notes
